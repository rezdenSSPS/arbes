# Game audio

All sounds of the game are generated by `gen_airsoft_audio.py` (stdlib-only Python, `dsp.py` = the
small DSP toolkit). Each sound has a fixed random seed, so a re-run reproduces the same files.

```bash
python3 -I tools/audio/gen_airsoft_audio.py            # everything (~20 s)
python3 -I tools/audio/gen_airsoft_audio.py shot_ ui_  # only names starting with these
```

- One-shots: `Assets/Resources/AirsoftAudio/Sfx/<name>_<n>.wav` (mono 44.1 kHz; `_n` = variations,
  the game picks one at random). Music / ambience loops: `Assets/Resources/AirsoftAudio/Music/*.ogg`
  (needs `ffmpeg`, otherwise `.wav`).
- To replace a sound, drop a clip with the same name in the same folder; to add variations, add
  `_4`, `_5`, ... files. `Assets/Editor/AirsoftAudioSetup.cs` sets the import settings.
- Mixer: `Tools > Airsoft > Audio > Create Mixer` rebuilds `AirsoftMixer.mixer`
  (Master > SFX / Music / UI, exposed `MasterVolume`, `SfxVolume`, `MusicVolume`, `UiVolume`).
- Runtime: `Assets/Scripts/FPS/Audio/` (`AirsoftAudio` = clips, voices, mixer volumes, music;
  `GameAudio` = match / objective sounds from synced state; `FootstepAudio`; `Surfaces`; `UISound`).
- Check: `Tools > Airsoft > Play Check: Audio` (or batch `-executeMethod AirsoftFPS.Editor.AudioPlayCheck.RunBatch`).
